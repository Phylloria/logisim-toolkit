# Changelog

## 1.0.0 - 2026-10-20

- Added standalone `logisim-toolkit` CLI and installable Python package.
- Added agent-neutral `AGENTS.md` and Claude Code adapter.
- Added bus-aware bit-level circuit model.
- Added Splitter decode/combine simulation.
- Added Adder, Comparator, Multiplexer, and Decoder support.
- Added D Flip-Flop, Register, and Counter state simulation.
- Added real bus and clocked Logisim validation.
- Added direct-wire checks for overlapping segments and dangling endpoints.
- Added 8-to-3, keypad, ALU, and hardware probe generators.
- Added four complete showcase circuits.
