# Showcase Circuits

These projects are complete native Logisim 2.7.1 deliverables, not screenshots
or truth-table substitutes.

| Project | Focus |
| --- | --- |
| `encoder_8to3` | 8-to-3 priority encoder, flat gate-level direct wiring |
| `decimal_keypad_flat` | 10-key decimal priority encoder, single flat circuit |
| `decimal_keypad_hierarchical` | Same interface split into three subcircuits |
| `alu16` | 16-bit gate-level ALU with eight operations and flags |

Each directory includes the `.circ` project and the strongest validation
artifacts produced for that design.
